## Цель работы
Алгоритмы с досрочным выходом из цикла. Алгоритмы обработки целых чисел. 
Задание данной лабораторной работы подразумевают разработку двух программ на языке C со стандартной работой через командную строку. 

## Требования к выполнению
1. Необходима проверка допустимости исходных данных, в том числе недопустим ввод строки вместо числа.
2. При вычислении результата необходимо использовать целый тип. Использование строк при решении данной задачи недопустимо.

## Программа принимает
**Для Части 1:**
- Целочисленную матрицу и массив (размеры и элементы вводятся через COM-порт).

**Для Части 2:**
- Массив целых положительных чисел (ввод через COM-порт).

## Формат вывода
**Для Части 1:**  
```Результат обработки матрицы (по заданию)```  
**Для Части 2:**  
```Новый массив (в соответствии с выбранным подпунктом)```

## Задание
### Часть 1
1. Обнулить максимальный по модулю элемент в строке матрицы Z, если его нет в массиве X.  
2. Удалить столбцы матрицы A, не содержащие нулей.  
3. Упорядочить столбцы матрицы F, если их произведение совпадает с элементом массива Q.  
4. Удалить строки матрицы D, содержащие только чётные элементы.  
5. Поменять местами max и min элементы в столбцах матрицы C, если они есть в массиве A.  
6. Поменять местами первую строку с нулём и последнюю без нулей в матрице A.  
7. Вычислить матрицу C из A и B, обнулить max элемент, если он есть в первом столбце A.  
8. Упорядочить столбцы матрицы A по убыванию, если все их элементы есть в массиве B.  
9. Удалить строки матрицы A, содержащие max элемент массива B.  
10. Найти max элемент матрицы A, отсутствующий в массиве B.  
11. Упорядочить строки матрицы A по возрастанию, если они содержат min элемент массива B.  
12. Обнулить элементы матрицы X, отсутствующие в массиве Z, и сохранить их.  
13. Сформировать массив Q из элементов столбцов Z после первого отрицательного, отсутствующих в F.  
14. Обнулить min и max элементы строк матрицы Y, если их нет в массиве A, и сохранить их.  
15. Упорядочить строки матрицы Q по убыванию, если их сумма есть в массиве Z.  
16. Упорядочить столбцы матрицы по возрастанию, если их произведение не совпадает с элементами Y.  
17. Удалить столбцы матрицы Z, все элементы которых отсутствуют в массиве P.  

### Часть 2
1. Сформировать массив из сумм цифр элементов исходного массива.  
2. Обратить порядок цифр в каждом элементе массива.  
3. Сформировать массив из произведений цифр элементов.  
4. Выбрать элементы-палиндромы.  
5. Сформировать массив из произведений первой и последней цифр элементов.  
6. Выбрать элементы, где суммы цифр на чётных и нечётных позициях равны.  
7. Подсчитать количество цифр Z в массиве и выбрать элементы, содержащие Z.  
8. Циклически сдвинуть цифры элементов вправо.  
9. Выбрать элементы, начинающиеся с цифры Z.  
10. Циклически сдвинуть цифры элементов влево.
