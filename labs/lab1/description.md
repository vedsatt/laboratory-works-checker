## Цель работы
Алгоритмы циклической структуры. Алгоритм «удаление путем сдвига». Алгоритмы поиска суммы, количества, среднего арифметического элементов массива.
## Требования к выполнению
1. Необходима проверка допустимости исходных данных.
2. В наборе тестов должны быть примеры, дающие все возможные варианты результатов.
3. Удаление элементов массива должно производиться путем сдвига, т.е. без формирования нового массива и с использованием одного цикла.
4. При отсутствии результата выполнения задания необходимо выводить на экран соответствующие сообщения.
```
❗Все три части оформить в одной программе.
```
## Программа принимает
1. Целое число n (1 ≤ n ≤ 200)- длина массива R  
2. Вещественные числа x, h, a (0 ≤ x, h, a ≤ 10^3>) - переменные для формулы
## Формат вывода
**Для первой части:**  ``` R[0] R[1] R[2] ... R[n] ```  

**Для второй части:** ``` R[0] R[1] R[2] ... R[n] ```
  
**Для третьей части:** ``` R[0] R[1] R[2] ... R[n] ```

*где R[i] - элемент массива R с вещественным числом с 5 знаками после запятой, полученным, после выполнения части задания*

### В случае некорректных данных формат вывода должен выглядеть так:
**Ввод:**
```
asd
```
**Вывод:**
```
Error: <описание ошибки>
```
*после этого программа должна заново начать ожидать ввод пользователя*
### В случае граничного случая (если в результате вычисления отсутствуют условия для выполнения 2-ой или 3-ей части) формат вывода должен выглядеть так:
**Ввод:**
```
1
5.2 0.5 1
```
**Вывод:**
```
<Вывод первой части>
Notice: <описание граничного случая>
```
### Если вы хотите добавить дополнительную информацию (например, указание номера лабораторной работы или номер задания), используйте следующий префикс: #>
**Пример:**
```
#> Лабораторная работа №1
#> Часть 1
<Вывод первой части>
#> Часть 2
...
```

## Задание
### Часть 1
Вычислить массив *R*[1:*n*] в соответствии с формулами:

1. Вычислить массив R[1:n] в соответствии с формулами: 

`r[i] = 2.5 sin(ax + i²h)`, i = 1,n и x,h,a - заданы
2. Вычислить массив R[1:n] в соответствии с формулами:

`r[i] = 1.25 sin(3ax - ih)`  
3. Вычислить массив R[1:n] в соответствии с формулами:

`r[i] = 6 cos(ax + ih)`  
4. Вычислить массив R[1:n] в соответствии с формулами:

`r[i] = 0.3 cos(2ax - i²h)` 
5. Вычислить массив R[1:n] в соответствии с формулами:

`r[i] = cos(ih) - cos(ax + ih)`  
6. Вычислить массив R[1:n] в соответствии с формулами:

`r[i] = 5.5 sin(ih) + cos(ax + ih)` 
7. Вычислить массив R[1:n] в соответствии с формулами:

`r[i] = 0.8 cos(8ax - ih)`  

### Часть 2
Из вычисленного массива R удалить:

1. Из вычисленного массива R удалить: 

Все элементы, удовлетворяющие условию: `|r[i]| < 0.7`
2. Из вычисленного массива R удалить: 

Все отрицательные элементы, расположенные до первого максимального элемента
3. Из вычисленного массива R удалить: 

Все положительные элементы, расположенные после первого отрицательного элемента
4. Из вычисленного массива R удалить: 

Все отрицательные элементы, расположенные между первым минимальным и последним положительным элементами
5. Из вычисленного массива R удалить: 

Все положительные элементы, удовлетворяющие условию: `r[i] < i/3`
6. Из вычисленного массива R удалить: 

Все положительные элементы, расположенные до последнего отрицательного элемента
7. Из вычисленного массива R удалить: 

Все элементы, расположенные после первого отрицательного элемента и удовлетворяющие условию: `|r[i]| >= 0.3`
8. Из вычисленного массива R удалить: 

Все элементы, расположенные между последним положительным и первым максимальным по модулю элементами
9. Из вычисленного массива R удалить: 

Все положительные элементы, расположенные после первого минимального элемента
